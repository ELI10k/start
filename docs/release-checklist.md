# Release checklist

- [ ] Tests, lint, TypeScript, and production build pass.
- [ ] Static and dynamic route smoke checks pass; unknown IDs return 404.
- [ ] Keyboard, focus, RTL, 320–1440px, reduced-motion, empty/loading/error states reviewed.
- [ ] Food audit reviewed; suspicious/missing source values accepted.
- [ ] No real client data, unapproved content, secrets, external calls, or payment code included.
- [ ] Authentication, authorization, backend persistence, server validation, monitoring, backups, privacy, and deployment completed before any production claim.
