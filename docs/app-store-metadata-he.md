# START — טיוטת מטא־דאטה ל־App Store

הטקסט מוכן להעתקה, אך יש לאשר אותו מול בעל העסק לפני ההגשה ולוודא שהוא
מתאר בדיוק את הגרסה שנשלחת.

## שם

START

## כותרת משנה

האימונים והתזונה שלך במקום אחד

## טקסט קידום

תוכנית אישית, מעקב פשוט ותקשורת ישירה עם המאמן — לאורך כל השבוע.

## תיאור

START היא אפליקציית הליווי האישית למתאמנים של START.

באפליקציה אפשר לצפות בתוכניות האימון ובתפריטי התזונה שהמאמן התאים עבורך,
לתעד ביצוע בזמן אמת, לעקוב אחר משקל ומדידות, לשלוח צ׳ק־אין ולשמור על קשר
ישיר עם המאמן.

מה מחכה לך באפליקציה:

- תוכניות אימון אישיות עם הנחיות, סטים, חזרות וזמני מנוחה.
- תפריט תזונה, סימון ארוחות ומעקב אחר צריכה יומית.
- סריקת ברקודים ותיעוד מזון בטקסט או בתמונה.
- מעקב אחר משקל, מדידות, תמונות התקדמות וצ׳ק־אין שבועי.
- הצגת צעדים מ־Apple Health לאחר מתן הרשאה.
- הודעות, תזכורות ותוכן מקצועי מהמאמן.

הגישה לאפליקציה מיועדת ללקוחות שקיבלו הזמנה מ־START. האפליקציה אינה תחליף
לייעוץ רפואי. ניתן להשתמש בתכונות שאינן תלויות ב־Apple Health גם ללא מתן
הרשאת בריאות.
